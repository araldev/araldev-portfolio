// The Project

An open-source design system.

v12-ui is a React component library focused on utility-first design and accessibility. The surfaces below are live — the GitHub repo where the package is developed, and the production Storybook that documents every component.

github.com/araldev/v12-ui

The repository where the library is developed: semantic-release automation, 25 tagged releases, MIT license, full README and About panel.

Storybook · Button/Docs

Live autodocs: 13 variant stories (Primary, Secondary, Muted, Accent, Success, Warning, Error, Info, Ghost, Border, Shadow variants), full prop table (as, href, variant, border, shadow, rounded), live controls panel.

Storybook · Toggle/Docs

WAI-ARIA switch component: variant, size, disabled, readonly, defaultChecked, checked, onChange. Full story list (Default, On State, Off State, Muted, Size Sm/Md/Lg, Disabled, Readonly, Controlled).

Storybook · AnimatedBackground

Canvas-based light-source animation. Particles drift upward with spring physics, mouse interaction, and lightsourced glow on every blob. Auto-disabled when prefers-reduced-motion is set.

Storybook · Accordion

WAI-ARIA accordion with arrow-key navigation. Default, muted, and ghost variants in three sizes (sm, md, lg). The sidebar reveals the full component tree: MagicLogo, MagicMouseFollower, MagicText, Stack, Accordion, AnimatedBackground, Button, Select, Text, Toggle.
